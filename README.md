# Sistema de Gestión de Reservas

Sistema web para gestionar clientes, servicios y reservas de una empresa de servicios, desarrollado con Spring Boot y PostgreSQL como proyecto del curso Herramientas de Desarrollo.

## Alcance de la versión 1.0
- Clientes: registrar, modificar, consultar
- Servicios: registrar, establecer precio y duración, consultar
- Reservas: registrar (cliente, servicio, fecha y hora), consultar, cancelar

## Pendiente para versiones futuras
Recordatorios automáticos, reportes, dashboard de indicadores, pagos en línea, historial de clientes.
